## 这个网站记录什么

项目开发中遇到的问题、数学建模的思考、论文阅读记录，以及其他值得写下来的事情。

文章支持 Markdown 标题、列表、引用和代码。数学内容会直接排版成公式。

## 公式与代码

例如，平方和记作 $S_n = \sum_{i=1}^{n}i^2$，它的闭式表达为：

$$
S_n = \frac{n(n+1)(2n+1)}{6}
$$

```python
def square_sum(n):
    return sum(i * i for i in range(1, n + 1))
```

矩阵同样支持：

$$
I_2 = \begin{bmatrix}1 & 0 \\ 0 & 1\end{bmatrix}
$$

## 发布文章

点击页面底部的「写文章」，填写标题、分类和正文，在预览里检查排版，然后点击「在 GitHub 发布」。

在 GitHub 完成提交后，网站会自动更新。文章文件保存在网站仓库里，可以随时修改，也可以将文章设为草稿。
