# Andrew Zhou 个人网站

网站：https://holly229567.github.io

管理页面：https://holly229567.github.io/admin/

布局参考 [PRISM](https://github.com/xyjoey/PRISM)：个人资料侧栏、学术内容主栏和清晰的论文列表。全站内容通过中文表单维护。

## 最简单的添加方式

在这台电脑上，双击项目目录里的 `管理网站.cmd`。管理台会在浏览器打开，并使用已有 GitHub 登录。选择栏目，点击添加，填写表单或上传文件，再点击右上角「发布更新」。

可以添加和维护：个人资料、联系链接、研究兴趣、简介、简历正文与 PDF、动态、经历、开源项目、论文、教学、奖项、学术服务、博客、自定义页面、头像、封面、图片、PDF、网站标题、配色与导航名称。

论文既可以填写表单，也可以粘贴或上传 BibTeX 批量导入。

## 网页管理

在这台电脑打开网页管理台，点击「打开已登录管理台」即可转到本机管理。网页里的未发布草稿和附件会转入本机页面；发布仍需在本机页面点击「发布更新」。GitHub 凭据不会传给网页。首次启动本机服务时双击 `管理网站.cmd`。

在其他电脑上可以直接打开管理页面，连接 GitHub 后使用同样的表单。使用仅授权本网站仓库、Contents 读写权限的细粒度访问令牌。令牌只用于当前页面与 GitHub API 通信，不保存在网站、备份文件或浏览器存储中。

## 草稿与发布

表单修改和未发布附件保存在当前浏览器的 IndexedDB。可以在「导入与备份」下载备份，也可以在另一台设备导入。发布会把内容和附件作为一次 GitHub 提交保存，自动部署网站。

这是公开的 GitHub 仓库。提交的数据，包括设置为不显示的文章，都可以在仓库中读取。私密草稿请保留在本机。

如果其他设备更新了网站，管理台会阻止覆盖旧版本。先导出草稿，再重新加载 GitHub 最新内容。

## 项目维护

`site.json` 是内容来源，`src/render.mjs` 控制网站结构，`src/site.css` 控制样式，`src/admin.mjs` 是表单管理台。图片和 PDF 放在 `public/uploads`。

本机管理服务只绑定 `127.0.0.1:5192`，写入请求需要同源校验与会话随机值。GitHub 登录凭据不会交给网页。

使用 Node.js 22 或以上。安装依赖后运行 `npm run build` 构建网站，`npm run dev` 预览静态输出，`npm run manage` 启动本机管理台。提交到 `main` 后自动发布。
